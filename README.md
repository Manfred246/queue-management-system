# Система управления очередью

## Назначение

Приложение предназначено для организации электронной очереди и упрощения обслуживания посетителей.

Система позволяет выбрать услугу, проверить возможность постановки в очередь, выдать талон, определить его статус и приблизительно оценить время ожидания.

## Целевая аудитория

Основные пользователи системы:

- посетители организаций, использующих электронную очередь;
- сотрудники, обслуживающие посетителей;
- администраторы, управляющие услугами и очередями.

## Предметная область

Предметная область проекта — управление потоком посетителей в организации с помощью электронной очереди.

Пользователь выбирает необходимую услугу и получает талон. Талон связывает пользователя с выбранной услугой и конкретной очередью.

В дальнейшем система должна хранить состояние очередей, порядок вызова талонов, сведения об услугах и пользователях.

## Основные сущности

- **Пользователь** — посетитель или сотрудник системы.
- **Очередь** — последовательность талонов на обслуживание.
- **Услуга** — вид обслуживания, который может выбрать пользователь.
- **Талон** — запись о постановке пользователя в очередь на выбранную услугу.

## Основные функции

1. Проверка возможности выдачи талона в выбранную очередь.
2. Формирование номера нового талона.
3. Расчёт примерного времени ожидания.
4. Определение текущего статуса талона.

## Начальный сценарий ПР1

В текущей версии реализован сценарий получения талона посетителем:

1. пользователь вводит своё имя;
2. выбирает одну из двух услуг;
3. указывает количество посетителей перед ним;
4. программа проверяет, открыта ли очередь и доступна ли услуга;
5. при успешной проверке формируется новый номер талона;
6. рассчитывается примерное время ожидания;
7. выводятся данные талона, время выдачи и его статус.

На этапе ПР1 используются только базовые возможности Python:

- простые типы данных;
- операции;
- преобразование типов;
- условные конструкции;
- функции;
- импорт стандартного модуля `datetime`.

Коллекции, циклы и классы намеренно не используются, так как они относятся к следующим этапам проекта.
